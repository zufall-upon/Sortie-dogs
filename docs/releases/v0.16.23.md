# v0.16.23 — Timed operation boundary correction

## Changes

- Reject additional shell commands and input redirections appended to a declared timed operation, including LF and CRLF boundaries. This corrects an operation-observation gap in v0.16.22.
- Preserve existing matching for valid timed operations, declared redirects, failure results, and observation ownership. The fix covers the public Mission tool hook and both plain and explicitly timed declarations.
- The change does not recover uncollected operations from other owners or runs and does not establish recovery of the original live operation.

# v0.17.3 — Git write-gate and Worker settlement

Scoped Git commits can use the invocation-local `commit.gpgsign=false` setting alongside identity options without relaxing native permissions, index scope checks, or restrictions on other Git configuration and repository overrides. Simple Python display expressions containing quoted data are no longer mistaken for Git write commands; actual Git write protection remains in place.

The V2 host adapter retains the admitted owner of a nested Worker when a native call returns an implicitly backgrounded Job. Foreground settlement retains its terminal output for recovery if accounting fails, and reconciliation keeps the actual terminal and required validation outcome distinct.

The runtime asset marker is `0.17.3-git-worker-settlement-v1`. Installing a package does not change an already-running shared host; restart remains a separate manual operation. These changes do not establish recovery of any particular production Mission.

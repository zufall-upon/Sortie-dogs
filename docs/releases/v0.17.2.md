# v0.17.2 — Review collector recovery

Review source collection handles inherited non-worktree Git directories as declared filesystem outputs. Git metadata bytes remain fingerprinted while their contents are omitted from automatic Reviewer excerpts and diffs, including in nested repositories.

When an unrelated historical file cannot be read because of permissions, Review reports the uninspected coverage rather than treating its bytes as verified. Current inputs and validation-bound files remain strict, and an unknown coverage gap cannot silently become a low-risk Review skip.

The runtime asset marker is `0.17.2-review-collector-recovery-v1`. Installing a package does not change an already-running shared host; restart remains a separate manual operation. Fixture results do not establish recovery of the original production Mission or an actual model-backed CLI startup.

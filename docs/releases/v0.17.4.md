# v0.17.4 — Mission continuity and recovery

Native V2 worker reconciliation can use a matching child's persisted idle outcome when the public
event history lacks a terminal event. Active or unproven writers remain reserved; formal validation
and accounting remain separate.

Explicit same-author continuation preserves the current user intent and predecessor evidence without
transferring prior Mission authority. Reviewer independence and active-writer protection remain in
place. Natural-language recognition is pattern-based and does not cover every possible formulation.

Recovery can resume direct planning after a quiescent Coordinator, reconcile failed Reviewer
corrections, and traverse more than 256 settled descendants without releasing active or unknown
writers. Exceptionally large individual native histories or child listings can still be unproven.

The runtime asset marker is `0.17.4-mission-recovery-v1`. Installing a package does not reload an
already-running shared host, and these changes do not establish recovery of a particular real Mission.

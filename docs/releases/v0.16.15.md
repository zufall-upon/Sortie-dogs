- Require all declared ordinary-Worker checks, not only the terminal criterion, before settlement, Review and acceptance. Retain command order, cwd, actual outcomes and live input bindings. Missing, failed or stale checks cannot become full proof; genuine successful retries remain possible.
- Synchronize native Reviewer recipe corrections with formal goal registration, including reload. Reusable cached PASS evidence retains original proof IDs in the registration path; its skip notice is not represented as another check execution. Current binding checks still apply.
- Reconcile stale V2 background-launch status only with a unique same-session shell/job ID, command and native completion notification. Match freshness from invocation start, so short jobs ending before launch completion can release quiescence. Missing terminal proof still blocks overlapping writers; foreground validation exits and durable native history are unchanged.

- Correction admission inherits the current unit's input/write declaration rather than resurrecting superseded historical Review scopes. Old Review context and failed evidence remain preserved.

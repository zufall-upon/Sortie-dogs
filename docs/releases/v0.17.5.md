# v0.17.5 — Windows App Execution Alias entries

Exact Windows App Execution Alias entries can be declared for entry-only operations without following
their targets. Authorization and artifact evidence bind the parent and entry identity to the supported
reparse metadata; a changed or incompletely read entry is not silently accepted.

These checks do not make a later path-based operation atomic or prove package ownership. They do not
remove an app or deploy a package.

The runtime asset marker is `0.17.5-app-exec-entry-v1`. Installing a package does not reload an
already-running shared host; restart remains a separate manual operation.

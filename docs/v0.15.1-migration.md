# v0.15.1 migration status

v0.15.0 has a known Review stability defect: a dangling symlink in retained external artifact scope can throw `ENOENT` before `review_mission` dispatches its Reviewer. Its published tag, package and evidence remain unchanged. Do not remove historical scope, edit the ledger, delete unrelated links or create fake targets to bypass this failure.

The v0.15.1 candidate records the link identity and an explicit target-missing state in the artifact fingerprint and bounded Review preview. Resolved links outside declared physical roots, permission errors, loops and unexpected I/O failures remain errors. A required output with a missing target must still fail its validator. Link removal or replacement observed after `lstat` is not classified as target missing.

It did not report the cancelled previous Mission as resumed. Existing v0.14.9-to-candidate migration and nonempty-reflection preservation evidence remains available. The main candidate also passed the related tests, full validation, independent source Review and candidate preflight.

The release decision uses that formal continuity together with the migration and actual recovery-path evidence. Reviving the cancelled Mission ID or reloading the shared host is not an additional release prerequisite. The isolated recovery result does not claim that the previous shared-host Mission resumed, and installing a package on disk does not establish the version loaded by an already-running host. Actual cumulative cost remains unknown.

Global application must verify every packaged file, runtime asset, version marker and CLI target while preserving explicit configuration, service registration, reflection and other plugins. Only successful deployment comparison permits the fixed-commit tag and GitHub Release. Root acceptance remains a separate comparison with all original requirements. npm publication remains manual. Do not restart the shared host without authorization, edit raw state or remove historical evidence to bypass failures; no reload experiment is required by this release procedure.

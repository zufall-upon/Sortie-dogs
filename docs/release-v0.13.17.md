- Put already-computed model, scoped cost and next-action status facts before bulky evidence on separate lines, including V2 decoration. Keep full JSON and existing acceptance semantics.
- Report native Mission completion separately from exact Worker-model coverage in complete-mode CLI probes; keep their acceptance predicate and official task correctness separate. Distinguish echoed source text from official collection/import failures and deduplicate observed test IDs without changing scores.
- Consolidate source-backed public caller/output assertions, client-state interactions, cleanup order, explicit-effect preconditions, return shape/missing values and mutation contracts. Reuse relevant tests within existing work, not another matrix, unit, gate or review round. Verified PR creation/merge uses standing authority without another owner question.

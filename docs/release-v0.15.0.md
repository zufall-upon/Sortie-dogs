# v0.15.0 — Project Memory and return reports

Release candidate; publication and installation are separate from source validation.

- OpenCode v010 gains opt-in project memory: public source observations, semantic events,
  current snapshots and durable pending work. Ordinary Operator reasoning records corrections,
  withdrawals and decisions; there is no dedicated model call per turn or new role.
- Empty-query resume prioritizes current adopted project vision and constraints within the
  existing 24-entry limit. Superseded or withdrawn positions are not revived. `protected_omitted`
  reports overflow; explicit searches retain relevance ordering. Memory is not authority.
- Existing Advisor consultations distinguish independent initial evaluation, adoption/rejection
  reasons and measured versus unverified effects. Operator compares the original request with
  actual outputs, checks, Review and remaining gaps rather than accepting completion prose.
- Restore the host-authored game-style return panel once in the final V2 reply. The historical
  removal dates, transport boundary and actual native final evidence are documented in the
  [implementation and qualification record](v0150-project-memory.md).

Enable with `sortie-dogs memory on .`, then reload the project plugin. `memory off .` stops
capture and recall, retaining existing data. Original attachment retrieval is explicit and does
not inject inline image base64 into routine recall. Existing reflection data, defaults, TTL and
explicit settings remain independent. Natural capture is OpenCode v010 only, not a new Codex
feature; existing Codex regression checks remain part of the common suite.

Real OpenCode 2.2.0/SOL observations include natural correction, new-session recall, off,
Advisor response and disposition/effect recall, rejection of an incomplete completion claim,
and a bounded implementation Mission with formal checks, independent Review, receipt and an
exactly-once host panel in the native final reply. These are not universal completion guarantees,
desktop-rendering or image-generation measurements. Costs remain unknown, not zero.

Development used the requested browser ChatGPT consultations; the shipped Advisor remains
model-replaceable and does not require browser automation. Before release, preserve the fixed
main commit, one tarball/SHA-256, candidate preflight, mandatory full suite, installed-byte/asset
comparison and tag/GitHub Release. npm publication remains manual. No stopped benchmark is resumed.
